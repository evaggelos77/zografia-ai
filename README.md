# Ζωγραφιά με Ζωή AI

Η ζωγραφιά του παιδιού **ζωντανεύει**: ανεβάζει φωτό ή τραβάει με την κάμερα,
η AI «βλέπει» τη ζωγραφιά (OpenAI Vision), φτιάχνει μια μικρή χαρούμενη
ιστορία στα Ελληνικά και της δίνει **πραγματική γυναικεία φωνή** (OpenAI
Shimmer). Παιχνιδιάρικα εφέ, ασφαλές περιεχόμενο, gallery τοπικά στη συσκευή.

## Πακέτα
- **Δωρεάν δοκιμή** — 3 ζωντανέματα
- **Basic €2,99/μήνα** — 15 ζωντανέματα τον μήνα
- **Full €5,99/μήνα** — απεριόριστα
- **Ετήσιο €49,99** — απεριόριστα (εξοικονόμηση)

## Τεχνικά
Static PWA. Καλεί `zografia-backend.onrender.com` για AI/Stripe.
Όλα τα προσωπικά δεδομένα (φωτογραφίες, στοιχεία) μένουν **τοπικά** στη συσκευή.
